# Сложно сосредоточиться

Адаптивная страница в тёмной и светлой цветовых темах. Учебный проект курса «Фронтенд-разработка» Яндекс Практикума, спринт «Вёрстка. Адаптивность и графика».

Макет: [Figma](https://www.figma.com/design/qhgelUhPHUbJVf3jgZsaD7/3-%D1%81%D0%BF%D1%80%D0%B8%D0%BD%D1%82.-%D0%9F%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%BD%D0%B0%D1%8F-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0)

## Что внутри

- Вёрстка по подходу Mobile First под три ширины экрана: 375, 768 и 1024 пикселя. Между ними страница «резиновая», горизонтальной прокрутки нет.
- Две цветовые темы: тёмная («Неон», основная) и светлая («День»). Кнопки в шапке переключают тему принудительно, режим «Авто» следует настройкам системы (`prefers-color-scheme`).
- Цвета вынесены в CSS-переменные, у переменных заданы запасные значения.
- Шапка и подвал занимают высоту экрана (`vh`) с минимальной высотой в пикселях.
- Фоновое изображение закреплено на всей странице (`background-attachment: fixed`).
- Раскладка построена на `grid`, для галереи используется `object-fit`.

## Структура проекта

```
index.html          разметка страницы
fonts/              шрифты IBM Plex Mono и fonts.css
images/             картинки, фоны и иконки сайта
scripts/script.js   переключение цветовых тем
styles/
  globals.css       сброс и глобальные стили
  variables.css     палитра, цвета тем и размеры под устройства
  style.css         основные стили (тёмная тема, три ширины экрана)
  dark.css          принудительное включение тёмной темы
  light.css         светлая тема: системная и принудительная
```

## Как запустить

Проект статический, сборка не нужна. Откройте `index.html` в браузере или поднимите любой локальный сервер, например:

```
python3 -m http.server 8000
```

После этого страница будет доступна по адресу http://localhost:8000.

## Технологии

HTML5, CSS3 (grid, flex, переменные, `prefers-color-scheme`, `clamp`), немного JavaScript для переключателя тем.
